# tl-portfolio

Site institucional estático da Thiago Serralheria, uma serralheria da Baixada Santista especializada em portas, portões e esquadrias de alumínio. Construído com HTML, CSS e JavaScript puros, sem dependências de build. Destina-se a clientes que desejam conhecer os serviços e solicitar orçamentos.

## Funcionalidades

- Apresentação dos serviços (portas, portões automáticos, esquadrias e manutenção)
- Carrossel de projetos realizados
- Seção sobre a empresa com estatísticas
- Formulário de contato para solicitar orçamento
- Botão de atalho para WhatsApp

## Como usar

O site é estático e não requer build ou instalação. Abra o arquivo `index.html` diretamente no navegador ou sirva a pasta com qualquer servidor estático:

```bash
python -m http.server
```
